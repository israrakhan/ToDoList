# Professional To-Do List Application

A modern, visually stunning, and interactive To-Do List web application designed with professional-grade frontend technologies. This app features a glassmorphism-inspired UI, advanced animations, and a sleek tech-themed background, making task management both productive and enjoyable.

## Features

- Add, edit, and delete tasks with ease.
- Set task priority levels: High, Medium, Low - with color-coded badges.
- Assign tasks to categories: Work, Personal, Learning, Career, Health.
- Real-time statistics dashboard showing total, completed, pending tasks, and completion progress.
- Interactive filtering (All, Active, Completed), sorting (Date, Priority, Category), and text search.
- Smooth animations for task actions (add, complete, delete) and button interactions.
- Responsive design for desktop and mobile devices.
- Glassmorphic UI design with frosted glass effects and premium typography.
- Tech-inspired geometric background for a polished and professional look.
- Accessible keyboard and mouse interactions.
- In-memory data storage with clear UI warnings about data persistence.
